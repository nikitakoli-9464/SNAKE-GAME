🐍 SNAKE GAME

A playable browser-based Snake Game developed for a college coding competition.

📌 Problem Statement

Problem 7 – Snake Game

Feature Set A

- Snake Movement
- Food Generation
- Score
- Game-Over Detection
- Replay

🎮 Features

- Touch and swipe controls
- 5 playable levels
- Score and high-score tracking
- Level-specific obstacles
- Pause and Resume
- Game-over and Replay
- Responsive mobile-friendly design

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Canvas API
- Python
- Flask
- SQLite

🤖 AI Tool Used

Google Gemini Canvas was used as an AI-assisted development tool for creating the game.
